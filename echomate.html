Why Project EchoMate Feels Completely Different

Built as a conversational arena, not an academic testing ground.

🎙️

Zero Mid-Thought Interruptions

Being interrupted destroys flow. EchoMate never buzzes you for misplaced prepositions. It listens to your full thought and mirrors natural phrasing organically inside its reply.

🎭

10+ Modes & Custom Sandboxes

Fluency is contextual. Jump into technical architecture defense, salary negotiations, or casual banter—or build your own custom sandbox for tomorrow's exact client meeting.

Episodic Diagnostic Memory

A coach that actually remembers you. Tracks your recurring phrasing habits, phonetic slips, and crutch words across sessions to build genuine long-term articulation muscle.

The Flight Simulator Philosophy

A Conversation Simulator, Not a Grammar Quiz

Pilots don't learn to fly by reading textbooks about aerodynamics; they log hours in a flight simulator. EchoMate lets you log speaking hours on topics you actually care about—cricket, distributed systems, or startup ideas—so English becomes an automatic muscle response.

  • • Study First, Speak Later:

    Forces users through repetitive flashcards, spelling tests, and grammar drills.

  • • Penalty & Fear:

    Red X marks and buzzer sounds trigger performance anxiety and speaking hesitation.

⚡ Project EchoMate Approach

  • • Speak Freely First:

    Pure conversational immersion on whatever topics interest you. No grammar placement tests.

  • • Zero-Judgment Flow State:

    Express complete thoughts without fear of sudden corrections or public embarrassment.

  • • Total Scenario Freedom:

    Rehearse real workplace conversations, standups, or debate custom ideas out loud.

Engineering Deep-Dive

End-to-End Vertical AI Architecture

How EchoMate coordinates ultra-low latency voice streams, dynamic system prompt synthesis, multi-LLM specialized routing, and persistent episodic memory.

Tier 1: Client Application Flutter / FlutterFlow • Opus Audio

Cross-Platform Mobile Interface

Captures bidirectional streaming audio with real-time waveform visualization, renders low-latency conversational transcripts, and displays interactive post-session diagnostic cards without blocking the voice loop.

▼   WSS / HTTPS (Supabase JWT Auth)   ▼
Tier 2: Edge Network & Gateway Cloudflare Workers • WSS Proxy

Global Edge Routing & Rate Limiting

Proxies bidirectional audio WebSockets, verifies JSON Web Tokens, terminates TLS close to the user in South Asia, and applies DDoS protection and intelligent session caching.

▼   Authorized Session Handshake   ▼
Tier 3: Backend Orchestration Supabase Edge Functions • Deno TypeScript

Micro-Orchestration & Dynamic Prompt Engine

Serverless Deno workers that inject user memory into system prompts and route queries to the optimal specialized AI model:

/session-init — Reads user target role and last 5 recurring errors to synthesize runtime prompts.
/ai-orchestrator — Dispatches voice frames and analytical workloads based on latency budgets.
/diagnostic-distill — Asynchronous post-session worker calculating CEFR, WPM, and error vectors.
▼   Smart Dynamic Task Dispatch   ▼
Tier 4: Multi-LLM Inference Mesh Specialized Model Routing

Hybrid Model Allocation Matrix

EchoMate does not rely on a single model. We route conversational turns, mock interviews, and evaluation pipelines to specialized engines based on their respective strengths:

🟣 Google Gemini Primary real-time conversational streaming, multimodal audio processing, and implicit speech recasting.
⚡ Groq Cloud Sub-150ms TTFT LPU inference with Whisper & Llama 3 for instant transcription & grammar validation.
🧠 Mistral AI Deep grammatical distillation, CEFR-aligned scoring, and structured JSON diagnostics.
✖️ Grok (xAI) Candid technical mock interviews, tough cross-examination questions, and realistic banter.
☁️ Cloudflare Workers AI Edge-level embeddings generation, fast offline fallbacks, and real-time safety & tone evaluation.
▼   Persistent Memory & Context Ingestion   ▼
Tier 5: Data & Memory Layer Supabase • PostgreSQL • pgvector

Long-Term Episodic Learner Memory

Our database architecture records session trajectories and semantic error patterns with Row Level Security (RLS) enforcement:

🧠 learner_memory (pgvector)

Stores recurring speech slips with HNSW vector indexing for semantic similarity lookup across sessions.

📝 system_prompts

Versioned prompt catalog containing baseline personas and dynamic parameter injection schemas.

👤 user_profiles

Maintains target career roles (e.g., Software Engineer, PM), current fluency stage, and MTI tendencies.

📊 performance_diagnostics

Stores post-session scores: Words Per Minute (WPM), filler frequency, coherence, and executive summaries.

Concrete Over Abstract

The Post-Session Speech Modeling

Instead of unhelpful generic grades like "Grammar: 72%," EchoMate isolates key sentences from your conversation and demonstrates how a native speaker or senior leader would express that exact thought with executive polish.

📦 Example 1: Technical & E-Commerce Operations
🔴 Raw Spoken Input

"first day change the handle so our soup if I inventory didn't update properly"

🟢 Executive Polish

"On the first day, they changed the handle, so our Shopify inventory didn't update properly."

💼 Example 2: Workplace Standup & Timeline Adjustment
🔴 Raw Spoken Input

"Uh, I think we should, like, maybe move the deadline to next Tuesday?"

🟢 Executive Polish

"I propose we adjust the project timeline to next Tuesday to ensure quality."

🏛️ Example 3: Narrative Explanation & Architecture
🔴 Raw Spoken Input

"in starting they are start using stones"

🟢 Executive Polish

"Initially, they began using heavy stones to construct them."
